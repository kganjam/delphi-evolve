# TrpB ESM2 prior vs measured assay (descriptive)

Baseline experiment node. Evaluates label-free ESM2 (NVIDIA BioNeMo TransformerEngine checkpoint,
H100 job aijob-e00whrj05xvrnbfxtx) priors and simple supervised models against the measured
Johnston et al. 2024 TrpB growth data (CaltechDATA h5rah-5z170, CC0). Local CPU computation; the GPU
step happened earlier on Nebius and is not hosted by OpenResearch.
