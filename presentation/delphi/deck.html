Our own near-vacuous theorem compiled, passed the axiom audit, and was caught by an independent reviewer.

finite_domain_stable, in our Admissible file

Assumed: for every admissible mode n, NOT(det(J - qD) < 0).
Concluded: for every n, det(J - qD) >= 0.
A restatement. The length hypothesis is unused. It is not linear asymptotic stability.

A clean axiom audit certifies proof dependencies, not whether the statement says what its name claims. The reviewer's check did.

Replacement: a revised module compiles every admissible mode has trace < 0 and det > 0 (exit 0, standard axioms). Trace is derived; determinant positivity is assumed. No new mutants yet; eigenvalue and PDE correspondence not established.

This is the system working. Caught by independent review with exact witnesses, not by a machine detecting autonomously.
