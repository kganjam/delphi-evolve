def build_slides(f, led_ids, prov_head):
    P, T, Er, Sc, Rb, Bl, Bn, Kl = f["price"], f["turing"], f["errors"], f["scorecard"], f["robustness"], f["baseline"], f["bench"], f["kills"]
    fn = lambda *parts: '<div class="fn">' + " · ".join(parts) + "</div>"
    stamp = f"artifacts @ {prov_head[:8]}"
    brand = lambda i: f'<div class="brand"><i></i>Delphi · from candidate laws to checked theorems</div><div class="num">{i} / 6</div>'
    pend = '<span class="pend">pending</span>'
    notes = []

    # ---------------------------------------------------------------- slide 1: frame, survivors first
    s1 = f"""{brand(1)}
<h1 class="hero" style="font-size:58px;margin-top:70px">Delphi: from candidate laws to <em>checked theorems</em></h1>
<p class="lede" style="font-size:26px;max-width:1040px">Experts know the conditions behind a law. An agent applying that law to a new setting does not reliably check them. First what survived our day of work, then what did not.</p>
<div class="row" style="gap:18px;margin-top:8px">
 <div class="col card"><h3><span class="pf pr">Proved</span> compiled in Lean 4</h3><p class="small" style="margin:0;font-size:16px">A finite-domain Turing instance and a conditional Hamilton regression theorem, each under stated assumptions with rejected mutants.</p></div>
 <div class="col card"><h3><span class="pf si">Simulated</span></h3><p class="small" style="margin:0;font-size:16px">Nonlinear solver outcomes and the agent evaluation: {pend}</p></div>
 <div class="col card"><h3><span class="pf ob">Observed</span></h3><p class="small" style="margin:0;font-size:16px"><b>None.</b> We ran no experiment. The released enzyme baseline is appendix only.</p></div>
</div>
<div class="scope" style="margin-top:14px;font-size:15.5px"><b>The caveats are not our discovery.</b> What is new is only that a program checks them before a law is applied, and that we keep score against ourselves.</div>
{fn('<b>Ledger</b> F01 F07 F05 P01 P02 P03 · planning/rethink/CLAIM-LEDGER.md', stamp)}"""
    notes.append("Delphi turns candidate laws into checked theorems. The conditions behind these laws are known to experts, so we do not present them as discoveries. The problem is an agent applying a law outside its scope without checking. First, what survived our day of work. Second, what did not. Everything is sorted: proved, simulated, observed. We ran no experiment. Unmeasured items are marked pending.")

    # ---------------------------------------------------------------- slide 2: Turing node
    scan = T["scan"]
    cells_h = "".join(f"<th style='text-align:center'>{E(s['L_over_pi'])}</th>" for s in scan)
    cells_v = "".join(f"<td class='{'u' if s['verdict'] == 'linearly_unstable' else 's'}'>{'grows' if s['verdict'] == 'linearly_unstable' else 'stable'}</td>" for s in scan)
    nmut = sum(1 for m in T["lean"]["mutants"] if m["exit"] != 0)
    w = T["windows"]
    sq = lambda x: x.replace("sqrt(", "√").replace(")", "")
    T_ww = f"L/π in ({sq(w['unstable_first'][0])}, {sq(w['unstable_first'][1])})"
    T_wb = sq(w["unstable_beyond"]).replace("*", "")
    T_gap = f"{sq(w['stable_gap'][0])} ≤ L/π ≤ {sq(w['stable_gap'][1]).replace('*', '')}"
    s2 = f"""{brand(2)}
<h2 style="font-size:31px;margin:24px 0 8px">Survivor 1: the continuum Turing conditions hold, yet a finite domain can admit <em>no growing mode</em>.</h2>
<div class="card" style="padding:8px 12px"><div class="small" style="font-size:14px;margin-bottom:4px">Declared model: J = [[{T['J'][0][0]}, {T['J'][0][1]}], [{T['J'][1][0]}, {T['J'][1][1]}]], diffusivities D = ({T['D'][0]}, {T['D'][1]}), 1-D Neumann boundaries; det(J − qD) = {T['det_factored']}, so the continuum band is {T['continuum_band'][0]} &lt; q &lt; {T['continuum_band'][1]}. Admissible modes are q = (nπ/L)².</div>
<table class="t3"><tr><th style="text-align:left">length L / π</th>{cells_h}</tr><tr><td style="text-align:left">linear verdict</td>{cells_v}</tr></table></div>
<div class="row" style="gap:14px;margin-top:10px">
 <div class="col card" style="padding:8px 12px"><h3><span class="pf pr">Proved</span> compiled instance</h3><p class="small" style="margin:0;font-size:14.5px">Lean {T['lean']['version']}: L = π admits no unstable mode; L = 2π admits one (n = {T['two_pi']['unstable_modes'][0]}, det = {T['two_pi']['n1_det']}). Build exit {T['lean']['build_exit']}; {nmut} law and domain mutants rejected. Only these two lengths are compiled.</p></div>
 <div class="col card" style="padding:8px 12px"><h3><span class="pf ex">Exact arithmetic</span></h3><p class="small" style="margin:0;font-size:14.5px">The whole strip above is exact rational arithmetic, not Lean-compiled. Over the reals with Mathlib, a host probe re-run by the director shows no admissible mode lies in the band at L = π.</p></div>
 <div class="col card" style="padding:8px 12px"><h3><span class="pf si">Simulated</span> / <span class="pf ob">Observed</span></h3><p class="small" style="margin:0;font-size:14.5px">Nonlinear solver check: {pend}. Observed tissue pattern: <b>none</b>.</p></div>
</div>
<div class="scope" style="margin-top:10px;font-size:14.5px"><b>Limitation first.</b> The algorithm is trivial: count admissible modes in the band; exact for rational L/π. The offer is a certificate and packaging, not new mathematics. Exactly, mode n grows iff {w['c_lo']}n² &lt; (L/π)² &lt; {w['c_hi']}n²: growth for {T_ww} and every L/π above {T_wb}; stable window {T_gap}. Non-monotone size dependence is textbook-derivable and not claimed as new; the literature citation is being verified.<br><b>Scope.</b> A linear-mode statement for this declared model, not whether a pattern forms; we are not saying Turing was wrong.</div>
{fn('<b>Ledger</b> F01 F02 (Mathlib probe: no ledger row yet, director receipt) · artifacts/turing_scope/results.json, lean_receipt.json · artifacts/rethink_director/MathlibProbe_host.lean', stamp)}"""
    notes.append("First survivor, limitation first. The algorithm is trivial: count admissible modes in the band. The offer is a certificate, not new mathematics. Take a declared model where the textbook condition holds. At length pi no mode is in the band, so it is stable. At three halves pi and two pi a mode grows; at five halves pi it is stable again. Only pi and two pi are compiled in Lean. Nonlinear simulation is pending.")

    # ---------------------------------------------------------------- slide 3: Hamilton node, ATLAS disclosed
    W = P["witnesses"]
    s3 = f"""{brand(3)}
<h2 style="font-size:30px;margin:24px 0 10px">Survivor 2: a <em>conditional</em> Hamilton regression theorem. The Price identity beneath it is not ours.</h2>
<div class="row" style="gap:20px">
 <div class="col" style="flex:.95">
  <div class="node pn" style="border-style:solid;color:var(--ink2);background:var(--card)">price · already in ATLAS, ours duplicates it</div><div class="arrow">↓ used by</div>
  <div class="node">selection_only · ours</div><div class="arrow">↓ used by</div>
  <div class="node">hamilton_regression · ours</div>
  <p class="small" style="font-size:13.5px;margin:8px 0 0">Dependencies are read from the Lean source. A critic's code search did not find the Hamilton form in ATLAS; that search is not exhaustive. Fisher's theorem is listed in ATLAS; we claim nothing there.</p>
 </div>
 <div class="col" style="flex:1.5">
  <div class="card" style="padding:8px 12px"><h3>Drop an assumption: the exact compiled witness</h3>
  <table style="font-size:14px"><tr><th style="text-align:left">assumption dropped</th><th style="text-align:left">what the witness shows</th></tr>
  <tr><td style="text-align:left">perfect transmission</td><td style="text-align:left">mean fitness × trait change = {W['transmission_is_needed']['mean_fitness_times_change']} while selection covariance = {W['transmission_is_needed']['selection_covariance']}</td></tr>
  <tr><td style="text-align:left">residual orthogonality</td><td style="text-align:left">trait mean rises although r·b − c = {W['residual_assumption_is_needed']['criterion_value']}</td></tr>
  <tr><td style="text-align:left">correct sign of the cost term</td><td style="text-align:left">the sign-reversed criterion is false on the same population</td></tr>
  <tr><td style="text-align:left">premises satisfiable?</td><td style="text-align:left">yes: change = {W['regression_premises_nonvacuous']['change']}, variance {W['regression_premises_nonvacuous']['var_z']}</td></tr></table></div>
  <div class="card" style="padding:8px 12px;margin-top:8px"><h3><span class="pf pr">Proved</span> receipt</h3><p class="small" style="margin:0;font-size:14.5px">Lean exit {P['original_exit']}; axioms: propext, Classical.choice, Quot.sound only. {len(W)} witness controls exit {P['witness_exit']}. {len(P['mutants'])} changed-target mutants rejected (exit {P['mutants'][0]['exit']}). Statement-fidelity review by a second reader: {pend}</p></div>
 </div>
</div>
<div class="scope" style="margin-top:10px;font-size:14.5px"><b>Established mathematics.</b> Price 1970; the Price–Fisher–Hamilton link is in Frank 1997. This is a statistical regression statement, not a causal cost–benefit rule.</div>
{fn('<b>Ledger</b> F07 · artifacts/integration/codex-api/price-probe.json (source sha ' + P['source_sha256'][:8] + '…) · experiments/price_probe/ · lean_price/README.md · interactive walkthrough: site/review/ (F09)', stamp)}"""
    notes.append("Second survivor. The Price identity is already formalized in ATLAS, so our version is a duplicate and we say so. What we add is the selection-only lemma and the conditional Hamilton regression theorem, with each assumption tied to an exact compiled witness. Two changed-sign versions are rejected by the compiler. Whether ATLAS has the Hamilton form is unchecked. This is a regression statement, not a causal rule.")

    # ---------------------------------------------------------------- slide 4: frozen test + checker
    fams = Bn["families"]
    s4 = f"""{brand(4)}
<h2 style="font-size:30px;margin:24px 0 10px">Survivor 3: a test set with exact answers, and a checker that refuses and proposes repairs.</h2>
<div class="row" style="gap:18px">
 <div class="col"><div class="card" style="padding:10px 14px"><h3>Test set, version 1.2</h3>
  <p class="small" style="margin:0 0 6px;font-size:16px"><b>{Bn['items']}</b> requests in <b>{fams}</b> families. Each states its conventions. Answer: applies, out of scope, or underdetermined, from exact arithmetic.</p>
  <p class="small" style="margin:0;font-size:15px">Key hash {Bn['key_sha256'][:8]}… · status: ready to freeze, <b>not approved</b>. Declared-model checks: nothing about tissues.</p></div></div>
 <div class="col"><div class="card" style="padding:10px 14px"><h3>Checker with repair</h3>
  <p class="small" style="margin:0 0 6px;font-size:16px">Exact linear-mode count on 1-D and 2-D domains; a repair enumerator that proposes a changed length or parameter and re-checks it. Ablations: record removed, record hash changed, continuum condition only.</p>
  <p class="small" style="margin:0;font-size:15px">Agrees with the key on <b>{Bn['oracle_audit']['agree']}</b> of {Bn['oracle_audit']['n']} items in {Bn['oracle_audit']['families']} families. Different workers wrote the two, same team and method; no ledger row.</p></div></div>
</div>
<div class="card" style="padding:10px 14px;margin-top:12px"><h3>Does an agent need it?</h3><table style="font-size:15px"><tr><td style="text-align:left">agent arms and matched budgets</td><td>{pend}</td></tr><tr><td style="text-align:left">coverage, false acceptance, false refusal</td><td>{pend}</td></tr><tr><td style="text-align:left">the scorecard of {Sc['records']} candidate laws</td><td>{pend}</td></tr><tr><td style="text-align:left">misprediction map over a large parameter ensemble: fraction stable on a finite domain</td><td>{pend}</td></tr></table></div>
<div class="scope" style="margin-top:10px;font-size:15px"><b>No scores shown.</b> A linear-mode verdict is not a pattern-formation verdict. A refusal is not a correct answer; an always-refuse baseline and the checker without a model are required comparisons.</div>
{fn('<b>Ledger</b> P01 P02 P03 · scopedesk/bench/v1_2/ (key sha in KEY.sha256) · scopedesk/bench/audit/oracle_layer_audit_v1_2.json · scopedesk/oracles/repair.py', stamp)}"""
    notes.append("Third survivor, a test set and a checker. One hundred thirty-one requests in eight families, each with declared conventions and an exact key. It is ready to freeze but not approved. The checker counts modes exactly and proposes repairs. It agrees with the key on all fifty-one items in three families; different workers wrote the two. Agent results, the scorecard and the misprediction map are pending. A refusal is not a correct answer.")

    # ---------------------------------------------------------------- slide 5: ledger of killed claims
    rows = "".join(f"<tr><td style='text-align:left'>{E(r['claim'])}</td><td style='text-align:left'><b>{E(r['kind'])}</b></td><td style='text-align:left'>{E(r['witness'])}</td><td style='text-align:left'>{E(r['ledger'])}</td></tr>" for r in Kl["rows"])
    s5 = f"""{brand(5)}
<h2 style="font-size:30px;margin:24px 0 8px">What did not survive, with the kind of failure kept separate and a witness for each.</h2>
<div class="card" style="padding:8px 10px"><table style="font-size:14.5px"><tr><th style="text-align:left">claim we held</th><th style="text-align:left">kind</th><th style="text-align:left">witness</th><th style="text-align:left">ledger</th></tr>{rows}</table></div>
<div class="row" style="gap:18px;margin-top:10px">
 <div class="col scope" style="font-size:15px"><b>Two of these were ours and were caught by independent review</b>, not by a machine acting alone. The near-vacuous theorem compiled and passed the axiom audit. A revised module compiles trace &lt; 0 and det &gt; 0 at every mode, with the determinant assumed (F10).</div>
 <div class="col scope" style="font-size:15px"><b>This is one team's hit rate in one day.</b> It is not a rate for the field, and no duration is shown because none was computed from the commit history.</div>
</div>
{fn('<b>Ledger</b> A01 F04 F05 F10 P01 P03 · planning/rethink/PRIOR-ART-VERDICT.md · lean_price/README.md · artifacts/integration/codex-api/service-fixed-review.json · artifacts/integration/codex-api/benchmark-semantic-audit.json · planning/rethink/CODEX-21-CLAIM-FREEZE-REVIEW.md', stamp)}"""
    notes.append("Now what did not survive, with kinds kept separate. Prior art: a first library, and our own Price lemma. Counterexample: a universal diffusion threshold, false at ratio one point one. Mis-operationalised: our liquid bridge key, our near-vacuous theorem, and an agent run whose prompts did not match its labels. Each has a witness. Independent reviewers caught ours. This is one team's hit rate in one day, not the field's.")

    # ---------------------------------------------------------------- slide 6: the one null, pending, credit
    s6 = f"""{brand(6)}
<h2 style="font-size:30px;margin:24px 0 10px">The one controlled comparison is a null. Then what is pending, and whose work this stands on.</h2>
<div class="row" style="gap:16px">
 <div class="col"><div class="card" style="padding:9px 14px;height:100%"><h3>Controlled comparison</h3><p class="small" style="margin:0;font-size:15px">Retrospective enzyme panel, {Bl['measured_nonstop']:,} measured variants: shared specialists <b>{Bl['shared_1000']}/100</b>, single planner <b>{Bl['q2c_1000']}/100</b>, a plain lazy search <b>{Bl['lazysp_1000']}/100</b>. <b>No collective advantage.</b> Shared lemma libraries have prior art (LEGO-Prover) and a negative replication.</p></div></div>
 <div class="col"><div class="card" style="padding:9px 14px;height:100%"><h3>Pending</h3><p class="small" style="margin:0;font-size:15px">Scorecard · agent evaluation · misprediction map · second-reader review of the Price statements · mutants for the replacement theorem · Turing statements offered to ATLAS · public use of the tool.</p></div></div>
 <div class="col"><div class="card" style="padding:9px 14px;height:100%"><h3>Credit, and what we do not claim</h3><p class="small" style="margin:0;font-size:15px">ATLAS (facebookresearch/atlas-lean), Prove2Me (arXiv 2608.28433), Rashid et al. 2017, lean-bio, crnt-lean, Ripple (arXiv 2607.13531). We aim to complement ATLAS. No experiment, no first library, no universal threshold, and no claim that a named law is wrong.</p></div></div>
</div>
<p style="font:500 26px/1.2 var(--serif);margin:18px 0 0;max-width:1120px">Make the assumptions behind a biological-model decision <em style="font-style:normal;border-bottom:4px solid var(--orange)">executable and auditable</em>.</p>
{fn('<b>Ledger</b> A01 A02 B01 B02 P07 P08 · planning/rethink/PRIOR-ART-VERDICT.md · artifacts/core/replay/table_primary.csv · artifacts/lazysp/results/table_primary.csv', stamp)}"""
    notes.append("One controlled comparison, and it is a null: shared specialists equal a single planner, 78 of 100 each, and a plain lazy search reaches 96. No collective advantage. Pending: the scorecard, the agent evaluation, the misprediction map, a second reader, and offering Turing statements to ATLAS. Credit: ATLAS, Prove2Me, Rashid, lean-bio, crnt-lean, Ripple. We claim no experiment and no first library. Make the assumptions behind a model decision executable and auditable.")
    return [s1, s2, s3, s4, s5, s6], notes
