Check 1: a finite domain can admit no growing mode

Limitation first. The algorithm is trivial: count the admissible modes that fall in the band. It is exact for rational L/π. What we offer is a certificate and packaging, not new mathematics. Non-monotone dependence on size is textbook-derivable, and we do not claim it as new. Finite-size effects on Turing patterns are in the literature; our citations for that are still being verified, so none is given here.

Declared model: J = [[1, -2], [2, -3]], diffusivities D = (1, 10), one-dimensional Neumann boundaries. det(J − qD) = (5q-1)(2q-1), so the continuum band is 1/5 < q < 1/2. Admissible modes are q = (nπ/L)². The continuum condition holds; whether a mode lands in the band depends on the length.

Stable at π, growing at 3π/2 and 2π, stable again at 5π/2. Exactly, mode n grows iff 2n² < (L/π)² < 5n². So the model grows for L/π in (√2, √5) and for every L/π above 2√2, and is stable in the window √5 ≤ L/π ≤ 2√2 (recomputed exactly by the trace check).

Each assumption has an exact compiled witness showing what breaks without it:

Drop: perfect transmission (transmission_is_needed)

descendant trait mean changes although selection covariance is 0, so the transmission term cannot be dropped

Drop: nothing (non-vacuity of the premises) (regression_premises_nonvacuous)

the theorem's hypotheses are satisfiable; with r=1, b=0, c=1 the criterion r*b-c=-1 predicts decrease and the change is -1/6

Drop: residual orthogonality (residual_assumption_is_needed)

with a residual correlated with the trait the trait mean RISES although r*b-c=-1 < 0

Drop: correct sign of the cost term (reversed_cost_is_false; plus 2 changed-target mutants the compiler rejects)

the sign-reversed criterion is false on the same population

Established mathematics. Price 1970; Frank 1997 links Price, Fisher and Hamilton. The Price identity is already formalized in the ATLAS biology library (facebookresearch/atlas-lean), so our version duplicates it; a critic's code search found no Hamilton form there, though that search is not exhaustive. This is a statistical regression statement, not a causal cost–benefit rule. A fixed-fitness variance corollary also compiles; it is not Fisher's theorem.

Our own validity errors, caught

The near-vacuous theorem

finite_domain_stable in our Admissible file assumed for every admissible mode n, NOT(det(J - qD) < 0) and concluded for every n, det(J - qD) >= 0. A restatement: the length hypothesis is unused and it is not linear asymptotic stability. It compiled and passed the axiom audit. An independent reviewer caught it, not us. A revised module (Admissible 469874b) compiles a stronger statement, finite_domain_linearly_stable: every admissible mode has trace < 0 and determinant > 0. Trace negativity is derived; determinant positivity is assumed. Lean exit 0, standard axioms. No new mutants have been run, and the full eigenvalue and PDE correspondence is not established (ledger F10). Mutants for it: pending.
