1. The reveal: length changes the answer

Declared model: J = [[1, -2], [2, -3]], diffusivities D = (1, 10), one-dimensional Neumann boundaries. det(J − qD) = (5q-1)(2q-1), so the continuum band is 1/5 < q < 1/2. Admissible modes are q = (nπ/L)².

Exactly, mode n grows iff 2n² < (L/π)² < 5n². The model grows for L/π in (√2, √5) and for every L/π above 2√2, and is stable in the window √5 ≤ L/π ≤ 2√2 (recomputed exactly by the trace check).

Proved compiled instance

Lean 4.35.0, build exit 0: L = π admits no unstable mode; L = 2π admits one (n = 1, det = -1/8). 3 mutants rejected. Only these two lengths are compiled.

Exact arithmetic

The strip is rational arithmetic, not Lean. Over the reals with Mathlib, a host probe re-run by the director shows no admissible mode in the band at L = π (no ledger row yet).

Simulated / Observed

Nonlinear check of this model: pending. Observed tissue pattern: none.
Limitation first. Counting admissible modes in a band is a trivial algorithm, exact for rational L/π. This is classical mathematics and a linear-mode statement for a declared model: it does not say a pattern forms, and we are not saying Turing was wrong. Non-monotone dependence on size is textbook-derivable and not claimed as new. The offer is a certificate and packaging.

2. The check and repair

Request

Target wavelength with equal diffusivities (Dv/Du = 1): 16 requests.

Exact refused

No admissible unstable mode (turing-ddi), a witness attached: 16 of 16. The plain formula accepts them.

Exact repair, then simulated

Raise Dv/Du to 9 (most requests); an independent solver finds a pattern on 11 of 16 requests; mean success 0.708 (fraction of 3 noise seeds, averaged over requests). The plain formula's design without repair: 0 of 16, by construction, since equal diffusivities admit no instability for any kinetics.
Caveats, printed. One kinetics (Schnakenberg), 1-D Neumann, 3 noise seeds, no confidence interval: a model-only check, not an experiment. Near-onset repaired patterns are marginal (amplitude up to 0.18 against a 0.10 threshold). The other 5 requests did not succeed on all seeds, and repairs for 2 further refusals worked on 0. No domain-length repair was found. Across 80 nonlinear configurations the gate agreed with the solver on 80 and the plain formula on 79; linear theory named the dominant wavelength in 43/61 patterned cases. Source: artifacts/rethink_nca/repair.json (not in the claim ledger yet).

Proved receipt

Lean exit 0; axioms: propext, Classical.choice, Quot.sound only. 4 witness controls exit 0. 2 changed-target mutants rejected (exit 1). The dependencies are read from the Lean source. The Price identity is already formalized in the ATLAS biology library (facebookresearch/atlas-lean), so our version duplicates it; a critic's code search found no Hamilton form there, though that search is not exhaustive. A regression statement, not a causal cost–benefit rule. Statement review by a second reader: pending

Each assumption has an exact compiled witness showing what breaks without it:

Drop: perfect transmission (transmission_is_needed)

descendant trait mean changes although selection covariance is 0, so the transmission term cannot be dropped

Drop: nothing (non-vacuity of the premises) (regression_premises_nonvacuous)

the theorem's hypotheses are satisfiable; with r=1, b=0, c=1 the criterion r*b-c=-1 predicts decrease and the change is -1/6

Drop: residual orthogonality (residual_assumption_is_needed)

with a residual correlated with the trait the trait mean RISES although r*b-c=-1 < 0

Drop: correct sign of the cost term (reversed_cost_is_false; plus 2 changed-target mutants the compiler rejects)

the sign-reversed criterion is false on the same population

Headroom check on the frozen test set

Unguarded models, no code tool: Claude Sonnet 5.5 121/127 (95.3%), Gemini 3.8 flash 110/127 (86.6%). Checker-tool arm not run. Effective n is 8 families. This measures judgement, not derivation, and is a coarse consistency check scored by the key's author; not a model ranking. Gemini's misses sit in wavelength (7 of 14) and Greenhill (6 of 13). It mostly shows the test set is not hard for a frontier model without tools. The "agents need the gate" claim is not supported by anything here.

Compiled proof-search pilot, 19 frozen integer-arithmetic lemmas

Same model, 3 replicates, 30 calls per run: every arm certified 19/19 in every run, a ceiling. Library reuse is real but saved nothing: median calls none 21, private 22, sequential 20, shared 21; median tokens 72k, 80k, 78k, 80k. Deterministic tactics certified 4/19. All 228 recorded proofs re-certified after the checker was repaired, a repair made after the outcomes (PREREG Addendum D). Call-matched, not compute-matched; the statements are arithmetic surrogates written by the experimenter, not biology, and Codex's fidelity review of them is advisory only.
