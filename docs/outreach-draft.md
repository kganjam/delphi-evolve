## To an enzyme-engineering group (decision-layer pilot)

Subject: Would an assumption-explicit "is this route open?" view help your next assay round?

Hello — we have a static page that takes a measured combinatorial landscape and tells you, per start/target pair, whether a route of single substitutions is admitted under an explicit assumed measurement error, which step is weakest, and which unmeasured genotype would need an assay. It is a retrospective prototype on public TrpB data; it has not been used on any lab's data and makes no claim about prospective uplift. If you have a combinatorial landscape with replicate measurements, we would like to learn whether the output changes which assay you would run. We are not asking for anything confidential and have no customer or pricing information to share.
