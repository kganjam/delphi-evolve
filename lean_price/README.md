# Price equation + Hamilton-rule (Queller-form) corollary — Lean 4 / Mathlib feasibility probe (critic, 2026-10-31)

Files: `Price.lean` (compiles, exit 0; only a linter warning), `PriceAxioms.lean` (same + `#print axioms`: `propext, Classical.choice, Quot.sound` only, for `price`, `queller`, `hamilton_form`), `PriceMutant.lean` (drops the transmission term E(w·dz): **fails**, exit 1) and `PriceMutant2.lean` (flips the sign of the partner term in the Queller corollary: **fails**, exit 1; the failure is the intended one — the sign mutant cannot be derived from the hypotheses). Build: `cd /data/artifacts/mathlib-probe && systemd-run --user --scope -p MemoryMax=12G -p MemorySwapMax=0 -p TasksMax=128 -p RuntimeMaxSec=580 lake env lean <path>/Price.lean` (about 40 s with the shared Mathlib cache). Lean toolchain `leanprover/lean4:v4.35.0`, Mathlib from `mathlib-probe`.

What is proved (finite nonempty population ι, reals, elementary definitions `E`, `Cov`, `zprime`; no measure theory):
1. `price`: E(w)·(z̄′ − E(z)) = Cov(w,z) + E(w·dz), where z̄′ = Σ w(z+dz)/Σ w, provided Σ w ≠ 0.
2. `queller`: if w_i = a + b1·z_i + b2·y_i + e_i exactly and Cov(e,z) = 0 then Cov(w,z) = b1·Var(z) + b2·Cov(y,z).
3. `hamilton_form`: with c := −b1, b := b2, r := Cov(y,z)/Var(z): Cov(w,z) = Var(z)·(r·b − c) when Var(z) ≠ 0 — so the sign of the selection covariance equals the sign of r·b − c **exactly when the stated linear-decomposition hypotheses hold**. Those hypotheses are the scope condition the textbook statement of Hamilton's rule omits.
Fisher's partial-change reading is the case z = w of (1) (Cov(w,w) = Var(w)); I did not state it as a separate Lean theorem.

What it is not: it is not a statement about any biological population; it does not prove Hamilton's rule is *true* for populations whose fitness is not exactly linear (there b and c are regression coefficients whose biological meaning is contested — see the 2025 eLife reviewed preprint on 'the general version of Hamilton's rule'); statement correspondence to the Delphi records (`hamilton-rule`, `fisher-ftns`) has not been reviewed by a second reader; the definitions are mine, not Mathlib's `covariance`.
Prior art (search-level, not exhaustive): the mathematics (Price 1970/72; Frank 1995 J Theor Biol 175:373; Frank 1997 Evolution 51:1712; Queller 1992) is classical, so 'the tree is shallower than it looks' is a known result in theoretical biology; I found no Lean/Coq/Isabelle/HOL formalization of the Price equation in three searches and no match in a grep of Mathlib; I did not search the Archive of Formal Proofs directly. Novelty at most: a machine-checked statement of the classical identity with its regression-partition scope condition.
